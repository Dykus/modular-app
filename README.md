# Модульное приложение для производства

Веб-приложение с модульной архитектурой для замены сетевой Excel-таблицы.
Несколько человек работают одновременно, никто никого не блокирует,
все изменения пишутся в журнал.

## Архитектура: ядро + модули

- **core/** — ядро: Flask, база данных (SQLAlchemy/SQLite), реестр модулей, настройки, журнал.
- **modules/** — подключаемые модули. Каждый самодостаточен (свои таблицы и страницы).
  Включаются/выключаются галочками в разделе «Настройки» без правки кода.
- **web/** — общий веб-интерфейс (шапка, меню, стили, темы).
- **data/** — база данных `database.db` и бэкапы.

## Модули

| Модуль | Адрес | Назначение |
|---|---|---|
| Задачи отдела (feedback) | `/feedback` | Трекер хотелок сотрудников со статусами и историей |
| Производство (production) | `/production` | Учёт под реальную Excel-таблицу (заполняется) |
| Журнал изменений (changelog) | `/changelog` | Лента «что добавлено / исправлено / изменено / удалено» |
| Версии (versions) | `/versions` | Управление релизами, страница «О программе» |
| Справка (help) | `/help` | Редактируемая документация по категориям |
| Настройки (settings) | `/settings` | Вкл/выкл модулей, тема, название, журнал изменений |

## Установка и запуск

Требуется Python 3.10+.

```
pip install -r requirements.txt
python run.py
```

Откройте в браузере адрес, который покажет консоль (по умолчанию http://localhost:5000).
Порт настраивается в `config.py` (`PORT = ...`); если порт занят, приложение
само возьмёт следующий свободный и напишет об этом в консоли.

Доступ по локальной сети: `http://IP-этой-машины:порт` (в `config.py` `HOST = "0.0.0.0"`).

## Структура папок

```
modular-app/
├── config.py            # порт, хост, путь к БД
├── run.py               # точка входа, автоподбор порта
├── requirements.txt
├── core/                # ядро: app.py, registry.py, models.py, database.py
├── modules/             # модули (feedback, production, changelog, versions, help, settings)
├── web/                 # общий интерфейс: templates/, static/
└── data/                # database.db (SQLite), бэкапы
```

## Примечания

- Данные лежат в одном файле `data/database.db`. Бэкап = копирование этого файла
  при закрытом приложении.
- Интерфейс в браузере — на русском; служебный вывод в консоли — латиницей
  (консоль Windows портит кириллиць при выводе).
- Паролей/ролей пока нет: сеть доверенная, но каждое действие пишется в журнал с именем.
  Авторизация — в планах.
