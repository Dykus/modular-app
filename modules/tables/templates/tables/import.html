Импорт из Excel — {{ t.title }}

← К таблице

Файл .xlsx читается на сервере. Колонки сопоставляются по названию заголовка (без учёта регистра и пробелов по краям). Строки добавляются в таблицу, существующие строки не меняются.

Как подготовить файл

  • Первая строка (или та, что укажете) — заголовки: они сверяются с названиями колонок таблицы.
  • Если хотите залить таблицу «с нуля»: сначала создайте в конструкторе колонки с теми же названиями, что в шапке Excel, — тогда всё ляжет точно по колонкам, включая числа и списки.
  • Пустые строки пропускаются. Даты из Excel переносятся в виде дд.мм.гггг.
  • Каждая добавленная строка получает отметку в «Истории клеток» (кто импортировал).
